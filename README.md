# אתונה 13–15.11.2026 | PWA

## העלאה ל-GitHub Pages
1. ריפו חדש, למשל `athens`.
2. Add file → Upload files → גוררים את כל הקבצים בתיקייה (בלי תיקיית משנה).
3. Settings → Pages → Branch: `main`, תיקייה `/ (root)` → Save.
4. אחרי 1–3 דקות: `https://nachlib.github.io/athens/`

## התקנה בטלפון
- אנדרואיד/Chrome: כפתור "התקנה" בראש המסך או ⋮ → "התקנת האפליקציה".
- אייפון/Safari: שיתוף → "הוספה למסך הבית".
- פעם אחת ב-Wi-Fi: מסך "מידע" → "שמירת כל התמונות".

## עדכון גרסה
משנים את `VERSION` ב-`sw.js` (כרגע v5) ואת `?v=` ב-`index.html`, ‏`app.js` (טעינת trip.json) וב-`sw.js`. האפליקציה תציג "יש גרסה חדשה" עם כפתור עדכון.

## בדיקה לפני הנסיעה
מסך "מידע" → "בדיקת המסלול" → בוחרים תאריך ושעה. או בכתובת: `index.html?now=2026-11-14T16:00`

## קודי אישור פרטיים
מסך "מידע" → "ההזמנות שלנו". הקודים מוזנים בטלפון בלבד ונשמרים רק ב-localStorage של המכשיר. הם לא נמצאים בקבצי האתר, לא נשלחים לשרת ולא נשמרים במטמון. זה מונע פרסום בטעות, אבל אינו אחסון מוצפן. באייפון יש להזין אותם אחרי ההתקנה למסך הבית, כי לאפליקציה המותקנת יש אחסון נפרד מ-Safari.

## מבנה גנרי
כל התוכן והטקסטים נמצאים ב-`trip.json`: ‏`trip` (כותרת, ימים, אזור זמן), ‏`places`, ‏`images`, ‏`steps`, ‏`info`, ‏`reservations` ו-`ui` (כל תוויות הממשק).
`index.html` הוא מעטפת ריקה ו-`app.js` מכיל לוגיקה בלבד. לטיול אחר מחליפים את `trip.json`, את `manifest.json` (שם האפליקציה) ואת קידומת המטמון ב-`sw.js`.
בכרטיסי מידע אפשר להשתמש בתבניות: `{s:stepId.field}`, ‏`{t:path}`, ‏`{d:day.path}`, ‏`{map:PLACE}`, ‏`{code:reservationId}`.
